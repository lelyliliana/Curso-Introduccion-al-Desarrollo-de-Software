# Glosario

[Inicio](../README.md) · [Siguiente recurso](cierre.md)

| Término | Significado en el curso |
|---|---|
| Algoritmo | Procedimiento definido para una clase de entradas |
| Argumento | Valor suministrado en una llamada |
| Base | Número de símbolos de un sistema posicional |
| Bit | Unidad con dos estados posibles |
| Byte | Ocho bits |
| Caso base | Situación que termina la reducción recursiva |
| Ciclo | Repetición controlada de instrucciones |
| Clave | Identificador de acceso en un diccionario |
| Complemento a dos | Convención con signo y ancho definido |
| Contrato | Entradas, resultados y errores acordados |
| Depuración | Localización y corrección de la causa de un defecto |
| Diccionario | Asociación de claves hashables con valores |
| Dominio | Contexto de problemas y reglas de aplicación |
| Entorno | Elementos externos al límite de un sistema |
| Incremento | Resultado utilizable añadido al producto |
| Inmutable | Objeto cuyo valor no se modifica en el lugar |
| Invariante | Propiedad que se conserva en puntos del algoritmo |
| Iteración | Vuelta de un ciclo o revisión de una solución según contexto |
| Límite de sistema | Frontera del análisis o control |
| Lista | Secuencia mutable de objetos |
| Modelo | Abstracción que permite estudiar un aspecto |
| Parámetro | Nombre de entrada en la definición de una función |
| Persistencia | Conservación de datos más allá de la ejecución |
| Prueba de regresión | Caso que protege frente al retorno de un defecto |
| Recursión | Operación definida mediante llamadas a sí misma |
| Requisito | Condición o capacidad esperada del producto |
| Sistema | Elementos relacionados con comportamiento conjunto |
| Trazabilidad | Relación entre requisitos, decisiones y evidencias |
| Validación | Comprobación de adecuación a la necesidad y contexto |
| Verificación | Comprobación de cumplimiento de especificaciones |
