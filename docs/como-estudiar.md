# Cómo estudiar el curso

## Recorrido de una lección

1. Lee el objetivo y explica qué resultado demostraría que lo alcanzaste.
2. Estudia la explicación y el caso resuelto. Escribe una predicción antes de mirar la salida.
3. En las prácticas de Python, abre el archivo y sigue el estado de las variables.
4. Ejecuta el ejemplo y compara el resultado. Si difiere, localiza el primer paso distinto.
5. Resuelve el ejercicio sin abrir su solución. Guarda el intento y al menos un caso límite.
6. Consulta la solución y explica las diferencias. Una alternativa también puede ser válida si cumple el contrato.
7. Responde las preguntas con tus propias palabras y usa Siguiente recurso.

## Organización de los ejercicios

Trabaja en una copia del repositorio o en una carpeta propia. Conserva los ejemplos originales para comparar. Nombra archivos y carpetas por tema. Guarda fuente, prueba de escritorio y resultados juntos. No uses nombres o datos personales reales en las prácticas.

La unidad 1 requiere documentos, tablas y modelos, no archivos Python para cada tema. En la unidad 2, Python ayuda a comprobar conversiones y tablas, pero también debes poder justificar los procedimientos manualmente. La unidad 3 enseña formalmente el lenguaje usado en esas comprobaciones.

## Cuando algo falla

Comprueba que guardaste el archivo y que estás en la carpeta correcta. Lee el mensaje completo. Distingue sintaxis, excepción y resultado incorrecto. Reproduce el caso más pequeño posible, compara con el contrato y cambia una cosa a la vez. Después de corregir, conserva una prueba del caso que falló.

## Criterios para revisar tu trabajo

Una entrega clara identifica problema, entradas, reglas y resultados; justifica decisiones; incluye pruebas de límites y describe lo que todavía no cubre. Poder ejecutar un programa es un punto de partida; comprender por qué funciona y dónde falla demuestra aprendizaje.
