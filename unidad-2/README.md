# Unidad 2. Sistemas de numeración y álgebra booleana

[Inicio del curso](../README.md) · [Mapa de contenidos](../docs/mapa-de-contenidos.md)

## Propósito

Relacionar representación de cantidades y lógica con el comportamiento de un sistema digital.

## Antes de comenzar

Descompón 345 como suma de centenas, decenas y unidades. Decide cuándo una frase que utiliza «o» admite ambas condiciones.

No necesitas dominar todavía todos los conceptos: conserva tu respuesta y revísala al terminar.
